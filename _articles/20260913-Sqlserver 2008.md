# 系统数据库

SQL Server 2008 有 4 个系统数据库，各自的作用如下：

**1. master 数据库**

- 记录 SQL Server 实例的所有系统级信息，是整个 SQL Server 的"总账本"
- 存储登录账户、系统配置设置、服务器上存在的其他所有数据库的信息（数据库名、文件位置等）
- 记录初始化信息，SQL Server 启动时首先加载 master 数据库
- 如果 master 损坏，整个实例可能无法启动，因此非常重要，需要定期备份

**2. model 数据库**

- 作为新建数据库的"模板"
- 每次执行 CREATE DATABASE 创建新数据库时，SQL Server 会先复制 model 数据库的内容作为新数据库的初始结构
- 如果想让所有新建的数据库都包含某些默认对象（如表、存储过程）或设置（如恢复模式），可以直接修改 model 数据库

**3. msdb 数据库**

- 主要供 SQL Server 代理（SQL Server Agent）使用
- 存储作业（Job）、警报（Alert）、操作员（Operator）的调度信息
- 记录数据库备份和还原的历史信息
- 还用于存储 Service Broker、数据库邮件（Database Mail）、维护计划等相关数据

**4. tempdb 数据库**

- 临时工作区，保存临时表、临时存储过程
- 存放查询执行过程中产生的中间结果集（如排序、哈希连接、游标等操作）
- 用于存储行版本控制信息（如启用了快照隔离级别或触发器等）
- 每次 SQL Server 服务重启时，tempdb 都会重新创建，不会保留数据

补充说明：SQL Server 2008 中还有一个隐藏的资源数据库（Resource DB），但它不对用户可见/可操作，通常不计入这"4个"系统数据库之列，主要存储系统对象的定义（如系统存储过程、系统视图等的代码）。
